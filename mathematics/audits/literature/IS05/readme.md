# IS05 source editions

## Yin

The retained [arXiv v2 HTML](../../../literature/pdf/IS05/arxiv-v2.html) is the public [arXiv:math/0405063v2](https://arxiv.org/html/math/0405063v2) edition cited in [Yin_L_A0017](../../../ledger/Yin_L_A0017_v1.md).
The native UTF-8 HTML preserves its MathML formulas, embedded image and native anchors; the [complete sidebar contents](../../../literature/contents/IS05/arxiv-v2.html.md) use those anchors.
The official v2 PDF endpoints returned HTTP 500, so the retained PDF is the earlier [19-page arXiv v1](../../../literature/pdf/IS05--arxiv-v1.pdf), submitted 4 May 2004.
The v1 PDF does not replace the v2 edition in the existing source citation, and no equivalence of their statements or numbering has been established here.
The [publisher record](https://www.sciencedirect.com/science/article/pii/S0022123604004215) supplies the 2005 journal metadata.
