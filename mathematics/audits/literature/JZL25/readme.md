<a id="global-dimension-background"></a>
## Selected source scope

Proposition 2.2 on [p. 6](../../../literature/pdf/JZL25--accepted.pdf#page=6) is the selected background reference for the bound on the global dimension of a group algebra by the group's cohomological dimension.
The passage uses absolute integral cohomological dimension, starting from a projective resolution over \(\mathbb ZG\); it does not state the version with \(\operatorname{cd}_{\mathbb C}(G)\) in its hypothesis.
The statement, coefficient scope and displayed tensor argument were read on 2026-11-12 for this distinction.
A formulation using \(\operatorname{cd}_{\mathbb C}(G)\) requires its own coefficient-field argument and is not attributed to the literal statement of this proposition.
The paper's general coherence theorems and their proof dependencies were not audited or adopted through this selected reading.
