# The scope of the trace-support statement for absolutely summable idempotents

<a id="ope26h-u001"></a>
<a id="trace-support"></a>
## Trace support and scalar characters

Theorem 1.1 in the OpenAI preprint of 5 October 2026 asserts the following for every discrete group \(G\) and idempotent \(e\in M_k(\ell^1(G))\).
For a conjugacy class \(C\) the coefficient in equation (1.1) is \(\sum_{g\in C}\sum_j e_{jj}(g)\).
All these sums are absolutely convergent.
The theorem asserts that the nonzero coefficients are supported on finitely many conjugacy classes of finite-order elements. [Theorem 1.1 and equation (1.1), p. 1](../../../literature/pdf/Ope26h.pdf#page=1).

For torsion-free \(G\) only the identity class can contribute.
Multiplication by a unitary scalar character is constant on each conjugacy class.
Consequently evaluating the diagonal trace at any such character gives the identity coefficient, which is the unnormalized regular matrix trace.
The character image is a numerical idempotent, so this value equals its ordinary rank.
The same grouping applies to a finite-dimensional unitary representation by using its normalized numerical character.

This inspection checked the authorship on the title page, the definition in (1.1), Theorem 1.1 and the discussion of the earlier literature in Section 1.1 on pp. 1–2.
The general preprint proof and its estimates have not been independently verified here.
The [published assembly implication](../BCM04/Yin_U001.md#amenable-projective-trace) supplies a separate source for countable groups with rationally surjective degree-zero Bost assembly, including countable groups with the Haagerup property.
