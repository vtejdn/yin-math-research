## Inspected edition

The selected original is [arXiv:0802.3956v4 in HTML](https://arxiv.org/html/0802.3956v4), retained as the [local HTML original](../../../literature/pdf/RV09/arxiv-v4.html).

The later date displayed inside the generated HTML is not the arXiv revision date.

The HTML provides MathML and TeX annotations, with its supplied navigation reproduced in the [searchable contents](../../../literature/contents/RV09/arxiv-v4.html.md).
