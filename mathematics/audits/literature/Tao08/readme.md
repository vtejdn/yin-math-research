# Tao08: simultaneous torus returns with bounded gaps

The selected original is Terence Tao's 13 January 2008 [254A Lecture 3](https://terrytao.wordpress.com/2008/01/13/254a-lecture-3-minimal-dynamical-systems-recurrence-and-the-stone-cech-compactification/).
The original HTML is retained at the logical local address `mathematics/literature/pdf/Tao08/lecture-3.html`, including native formula-alt text and source encoding.
Formula-image resources were not downloaded, so this is not a complete offline visual copy.

Theorem 2 and the following equation (4), together with the definition of almost periodicity preceding Lemma 1, were inspected on 2026-11-05.
For any fixed finite-dimensional torus rotation, simultaneous returns to any neighborhood of the identity have bounded gaps in the integers.
No rational independence of the coordinates is required.
Translating those return times by one gives repeated visits near the rotation vector itself.
The [reduced permutation argument](../../../claims/Yin_C_F0189_v1.md#independent-upper-limit-equality) uses this fact to select dimensions where all irrational polynomial roots stay a fixed distance from one.
That argument includes its own finite-net proof; the source supplies attribution for the standard recurrence fact.
No whole-lecture review or priority claim is made.
