# Vir19b and the Vir17 citation

## Yin

The [publisher DOI](https://doi.org/10.1515/taa-2019-0006) identifies the 2019 article on length functions and exact Sylvester rank functions, distinct from the entropy paper Vir19.
The public [arXiv v2 of Li21](../../../literature/pdf/Li21--arxiv-v2.pdf#page=17) attributes its Corollary 4.3 to this article as reference [30].
The DOI's public metadata identifies a six-page open-access journal article, but the publisher PDF requests returned empty HTTP 202 HTML responses and the Sciendo page returned HTTP 405.
No readable Vir19b original was obtained from those requests.
The exact relationship between this published article and the differently titled 2017 preprint Vir17 has not been established.
The [JZ19 source unit](../JZ19/Yin_U001.md#exact-rank-to-length) separately checks the usable extension theorem in Li21 without asserting that bibliographic identity.
