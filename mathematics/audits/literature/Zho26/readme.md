# Zho26: circular-addition density formulas

Source/version: Ping Zhong, *Brown measure of the sum of an elliptic operator and a free random variable in a finite von Neumann algebra*.
The [canonical bibliography](../../../literature/references.bib) records American Journal of Mathematics 148(1) (2026), 161--233, DOI 10.1353/ajm.2026.a980771, as verified from the publisher's Crossref deposit.

Coverage state: **Read**, contextual comparison, self-review.

For x bounded in a finite tracial von Neumann algebra and a circular c_t of variance t>0 which is scalar star-free from x, Xi_t consists of z with phi(|x-z|^-2)>1/t.
There the subordination parameter w>0 solves phi(((x-z)^*(x-z)+w^2)^-1)=1/t.
The density formula contains a positive two-resolvent trace and a nonnegative term arising from implicit differentiation.
This scalar subordination equation is not an identification with a matrix-optimizer problem.

Theorem 4.3 on the same page explicitly attributes the global density and regularized-density bound to BYZ24, Theorem 7.10 and Lemma 7.11.
Scalar freeness and circular variance are additional assumptions and are not inferred from arbitrary matrix-valued coefficients.
