# De Oliveira's real implicit and inverse function theorems

<a id="journal-edition"></a>
## Yin's source editions

The journal edition is signed Oswaldo de Oliveira and appears on printed pages 207–218 of *Real Analysis Exchange* 39(1), whose issue is marked 2013/2014.
The DOI record gives 2014 as the print publication year. [Journal record](https://doi.org/10.14321/realanalexch.39.1.0207), [author's journal PDF](https://users.ime.usp.br/~oliveira/IMPLI-1-RAEX-FINAL.pdf), [local journal edition](../../../literature/pdf/dO14.pdf)

The real implicit function theorem is Theorem 5 on printed page 214, the eighth PDF page.
In the earlier preprint, signed Oswaldo Rio Branco de Oliveira, the corresponding statement is Theorem 2 on pages 6–7. [Preprint v1](https://arxiv.org/pdf/1212.2066v1), [Yin's reading of Theorem 5](Yin_U001.md#do14-u001)
