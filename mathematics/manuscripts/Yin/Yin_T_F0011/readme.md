# On conjugate variables and dual systems

Responsible writer: Yin (Sheng Yin).
This manuscript develops the comparison between conjugate variables and dual systems from the completed [Task F0011](../../../tasks/Yin_T_F0011_v1.md#decision-complete-comparison).
It proves the equivalence between actual starred-core conjugate variables and strong full-domain dual systems for finite normal generating tuples, including uniform estimates for both slices and the original canonical domains.
It also gives both arbitrary-tuple separations and proves maximal Delta from the algebraic full-domain hypothesis.

- [Compiled manuscript](paper/main.pdf)
- [TeX entry point and build instructions](paper/readme.md)
- [Citation map](citation.md)

The paper is organized around the normal comparison and the nonnormal examples, with the maximality consequence proved alongside the domain arguments.
The appendix proves the lattice and projection transfers used in the analytic estimate.
The manuscript uses Yin's current [author-wide policy](../../../../profiles/Yin/writing/readme.md), [free-probability policy](../../../../profiles/Yin/writing/free_probability.md) and [terminology](../../../../profiles/Yin/terminology.md).
It is an English research manuscript for free-probability and operator-algebra readers.
The byline is omitted under the default for new manuscripts; this does not change the writer attribution above.
