# Eigenvalue Convergence for Polynomials in Independent GUE Matrices

Responsible author: Yin (Sheng Yin).
This manuscript presents the proof selected for [Task F0012](../../tasks/Yin_T_F0012_v1.md#decision-full-polynomial-proof).
It establishes weak convergence in probability to Brown measure for every fixed scalar polynomial in independent normalized GUE matrices.
