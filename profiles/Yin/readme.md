# Yin: Personal Policies

These are Yin's own defaults and explicitly scoped active policies.

The [preference rules](../../framework/rules/preferences.md) govern scope, precedence, partial inheritance and expiry.
No repository-adoption record is required.
Another operator does not inherit these defaults.
